## Notes on partial fixes

- **ux-iphone-05:** Done: an empty library shows 'Getting your conversations…' with a spinner while sync is checking, or while this install has no completed pass (the persisted controller.lastSync) or hasMoreWork. LibraryWords.isGettingConversations is unit-tested. Not captured visually, because the simulator has no iCloud. Left to w2-mac-capture-welcome per the plan: the iPhone Welcome.
- **ux-iphone-09:** Decision: keep 'Recording with Your Mac' as one switch that covers both directions and dims each Mac's switch while it's off. This is safe if applied partly and keeps an earlier 'off' meaning off. None of the needed edits fall in my files, and w2-link-pairing has already rewritten them, so they are written here against its versions. (1) PhoneAppModel+Cascade.swift: in askMacsToJoin's guard (`guard asksMacs, cascadesToMacs, …`) and in macConnectedDuringCascade's guard, add `settings.acceptsMacRecordRequests`, so when the switch is off the iPhone stops asking Macs to record. (2) In the Mac page's Can Start Recording toggle (MacDetailScreen / PeerDevicePage in link-pairing's version), add `.disabled(!model.settings.acceptsMacRecordRequests)`. (3) In PhoneAppModel.answer, replace both 'Recording with a Mac is turned off on this iPhone.' refusals with a PairingWords sentence in link-pairing's pattern: 'It isn’t set to record with Macs. Turn on Recording with Your Mac in Settings › Recording on the iPhone.' The per-Mac refusal is already PairingWords.notAllowedToStart(asker: .mac): 'It isn’t set to let this Mac start recording. Turn on Can Start Recording for this Mac on the iPhone.' (4) Add a row to the Preferences table in docs/multipoint.md: '\| Recording with Your Mac (on the iPhone) \| On \| `PhoneSettings.acceptsMacRecordRequests`; Settings › Recording. Off, this iPhone neither records when a Mac starts nor asks Macs when it starts, and each Mac's Can Start Recording is dimmed \|'. (5) Add a CascadingRecordingTests case: with the switch off, a start on the phone asks no Mac.
- **ux-iphone-24:** Done in my files: Mac line says 'Needs iCloud' (calm) when iCloud can't be used; compact Mac line, synced Mac row and idle paired Mac rows all use RecorderStatusWords.lastSeen ('Last seen today, 3:25 AM'), and a paired row takes the newer of the link's last connection and the Mac's sync presence instead of 'Last connected'. Not mine: MacPresence/stateLine wording (w2-link-pairing, which already moved MacPresence to lastSeen), MacSighting (w2-summary-page), and the 'Hand Back to My Mac' toggle in DeviceScreens.swift (w2-devices-screens).
- **ux-iphone-25:** PhoneAppDelegate is the UNUserNotificationCenterDelegate (set in didFinishLaunching): a tap opens AppDestination(userInfo:) (conversation, library, device, recording, new note; reads DaybookDevices' daybook.place/deviceID/conversationID keys), banners while in front. The model publishes destination; DestinationRouter/`.opensDestinations(session)` apply it to a ReadingSession.
